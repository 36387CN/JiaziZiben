#路线解剖

路由是用户必须穿过的一系列线段 从起点开始，抵达目的地韦庞特 航点。

每个段称为路由步，由两个定义 地理坐标以及用户在移动时必须执行的指令 在这条路线上，还有一些额外的数据。

每个阶梯之间的实际路线不必是直线 但 can 提供了自身复杂的几何形状。

#Waypoint

A Waypoint is a data structure that indicates and start or ending point of a Route. A Waypoint can be one of three types: User Location, Location, or Query.

  

  • User Location: In this case the Waypoint resolves to the current user location. Usually used for the starting point of the route.
  • Location: Resolves to a geo-location defined by latitude/longitude coordinates.
  • Query: Resolves to the first result of the mapbox Search API for the given query string.

#路标

这是我们对Monobehaviour的默认实现。它由三个组成部分组成：AbstractRouteSignpost

  1. 一个跟随用户的方向标志，显示下一个的字符串 台阶的动作以及距离当前台阶的距离。
  2. 一个3D箭头网格，显示用户必须前往下一步的方向。
  3. 当用户到达最终航点时，会显示一个3D终点标志。
