网页地图编辑器

该网页地图编辑器界面目前处于Alpha阶段，可用于在地图上放置标记，关联 将AR+GPS位置数据发送到这些标记器，并导出包含生成数据的XML文件，用于Unity内部， 这样AR+GPS定位插件会自动在指定位置创建物体。

#用途

首先，点击地图右侧你想放置标记的位置。最初这会在地图上放置一个红色标记。

这是临时标记。制作永久性马克笔时，请在右侧面板上填写必要信息。

大多数字段都是属性的完全复制。除此之外，你需要输入a代表位置，并且输入一个。这是字符串，必须匹配Unity中预制件的可脚本对象，我们将在下一节中详细介绍PlaceAtLocationNameMesh IDMesh IDMesh IDPrefabDatabase

之后，点击按钮。然后马克笔会变成蓝色，表示它变成了永久性马克笔，而且这个点 将出现在 。Add MarkerList of points

你可以通过在地图上或 .选中的标记会变成绿色。List of Points

你也可以通过在地图上拖动任何标记来更改它的位置。

添加所有想添加的标记后，点击按钮下载包含所有数据的XML文件。如果你愿意 如果想以后再次编辑同一数据，可以点击并上传同一个文件，在编辑器中恢复所有数据。Download XMLUpload XML

#将数据导入 Unity

首先，把你从网页编辑器下载的文件导入到Unity。你最终应该会得到类似这样的文本资源：XML

之后，开启一个场景。创建一个新的GameObject并添加一个组件。AR+GPS LocationWeb Map Loader

现在，在属性中选择你刚导入的文件。Xml Data FileXML

接下来我们需要一个 。要创建一个，右键点击面板并点击。Prefab DatabaseProjectCreate > AR+GPS Location > PrefabDatabase

这样应该会创建一个资源文件。选择后，你可以在检查器中编辑：PrefabDb

现在把你需要的条目加入这里。应该是网页地图编辑器里的 ，而且 是 你希望与该 ID 关联，即你想放置的对象在与 关联的位置。Mesh IdMesh IdPrefabPrefab/GameObjectMesh Id

创建后，只需将其添加到：PrefabDbWeb Map Loacer
